# CONTINUITY

Use this guidance when work needs durable handoff, recovery, or a decision that source and tests do not already explain. Small self-contained work may close inline.

## Useful handoff evidence

Record the accepted result, changed surfaces, meaningful checks, limitations, recovery, and exact unfinished item in one existing repository home. Identify the current owner when another task must continue.

Use the relevant `todo.md` record or source document. Link evidence instead of duplicating it. The former mandatory per-task template and signature fields are retired.

## Audit evidence

Describe the actual method and scope. Separate source checks, publication, installation, and live behavior. State consequential unknowns instead of rounding them up to completion.

## Existing homes

`todo.md` holds current work and verification records. `AGENTS.md` is the project entry. `COHERENCE.md` is a dependency reference. None requires loading all historical records at startup.
